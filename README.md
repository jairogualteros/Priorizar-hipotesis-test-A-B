# 🚗 Dashboard Interactivo de Mercado de Vehículos Usados (EE.UU.)

## 📌 Descripción del Proyecto
Esta aplicación web interactiva permite a los usuarios explorar y analizar un conjunto de datos sobre anuncios de venta de coches usados en los Estados Unidos. La herramienta facilita la identificación de patrones entre el precio de los vehículos, el kilometraje (odómetro), el año del modelo y su condición general.

---

## 🛠️ Tecnologías y Librerías
* **Lenguaje:** Python 3.x
* **Manipulación de Datos:** `Pandas`, `NumPy`
* **Visualización de Datos:** `Plotly Express`
* **Desarrollo Web & Despliegue:** `Streamlit`, Render

---

## 📊 Funcionalidades del Dashboard
* **Histogramas Interactivos:** Análisis de la distribución del kilometraje y precios de los vehículos.
* **Gráficos de Dispersión (Scatter Plots):** Evaluación de la relación entre el precio del coche y su kilometraje según el tipo de combustible o transmisión.
* **Filtros Dinámicos:** Casillas de verificación (checkboxes) e interruptores para personalizar la visualización de datos en tiempo real.
